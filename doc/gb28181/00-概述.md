# GB/T 28181-2016 概述

## 标准信息

- **标准编号**: GB/T 28181-2016
- **标准名称**: 公共安全视频监控联网系统信息传输、交换、控制技术要求
- **发布日期**: 2016-07-12
- **实施日期**: 2016-08-01
- **替代标准**: GB/T 28181-2011

## 标准范围

本标准规定了公共安全视频监控联网系统的信息传输、交换、控制技术要求，适用于公共安全视频监控联网系统的方案设计、系统检测、验收以及相关设备的研发、生产。

## 主要技术内容

1. **SIP协议**: 会话初始协议，用于建立、修改和终止多媒体会话
2. **SDP协议**: 会话描述协议，用于描述多媒体会话参数
3. **MANSCDP协议**: 监控报警联网系统控制描述协议，用于设备控制和信息查询
4. **MANSRTSP协议**: 监控报警联网系统实时流协议，用于录像回放控制

## 系统架构

### 核心概念

| 概念 | 说明 |
|------|------|
| SIP监控域 | SIP设备、SIP客户端和监控中心服务器构成的域 |
| 非SIP监控域 | 不支持SIP协议的监控系统 |
| 级联网格 | 上下级平台互联的网络结构 |
| 对等网格 | 平级平台互联的网络结构 |

### 功能实体

| 实体 | 说明 |
|------|------|
| SIP设备 | 支持SIP协议的监控设备（IPC、DVR、NVR等） |
| SIP客户端 | 用于访问监控资源的用户终端 |
| 中心信令控制服务器 | 处理SIP信令的核心服务器 |
| 媒体服务器 | 处理媒体流的中继、转发、存储 |
| 安全信令网关 | 跨域安全通信网关 |

## 通信协议栈

```
┌─────────────────────────────────────────┐
│           应用层 (MANSCDP/MANSRTSP)      │
├─────────────────────────────────────────┤
│           会话层 (SIP/SDP)               │
├─────────────────────────────────────────┤
│           传输层 (TCP/UDP)               │
├─────────────────────────────────────────┤
│           网络层 (IP)                    │
├─────────────────────────────────────────┤
│           媒体传输 (RTP/RTCP)            │
└─────────────────────────────────────────┘
```

- 增加 SSRC 生成规则
- 增加国标级联通信流程
