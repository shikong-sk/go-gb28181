# GB/T 28181-2016 录像回放与下载

## 概述

录像回放和下载是视频监控系统的重要功能，通过SIP INVITE建立会话，使用MANSRTSP协议控制播放。

## 录像文件查询

### 查询流程

```
平台                              设备
  │                                │
  │ ──── MESSAGE (RecordInfo) ────>│
  │                                │
  │ <─── 200 OK ──────────────────│
  │                                │
  │ <─── MESSAGE (Response) ──────│
  │                                │
  │ ──── 200 OK ─────────────────>│
```

### 查询请求

```xml
<?xml version="1.0"?>
<Query>
  <CmdType>RecordInfo</CmdType>
  <SN>17430</SN>
  <DeviceID>34020000001310000001</DeviceID>
  <StartTime>2010-11-11T19:46:17</StartTime>
  <EndTime>2010-11-12T19:46:17</EndTime>
  <FilePath>34020000002100000001</FilePath>
  <Address>Address1</Address>
  <Secrecy>0</Secrecy>
  <Type>time</Type>
  <RecorderID>34020000003000000001</RecorderID>
</Query>
```

### 查询参数

| 参数 | 说明 |
|------|------|
| StartTime | 查询开始时间 |
| EndTime | 查询结束时间 |
| FilePath | 文件路径标识 |
| Address | 地址 |
| Secrecy | 保密级别 |
| Type | 类型：time/alarm/manual/all |
| RecorderID | 录像设备ID |
| IndistinctQuery | 模糊查询标志 |

### 查询响应

```xml
<?xml version="1.0"?>
<Response>
  <CmdType>RecordInfo</CmdType>
  <SN>17430</SN>
  <DeviceID>34020000001310000001</DeviceID>

  <SumNum>100</SumNum>
  <RecordList Num="2">
    <Item>
      <DeviceID>34020000001310000001</DeviceID>
      <Name>Camera1</Name>
      <FilePath>34020000002100000001</FilePath>
      <Address>Address1</Address>
      <StartTime>2010-11-12T10:10:00</StartTime>
      <EndTime>2010-11-12T10:20:00</EndTime>
      <Secrecy>0</Secrecy>
      <Type>time</Type>
      <RecorderID>34020000003000000001</RecorderID>
```

## 录像回放流程

### 基本流程

```
平台                              设备
  │                                │
  │ ──── INVITE ──────────────────>│ (1)
  │      SDP (s=Playback)          │
  │                                │
  │ <─── 200 OK ──────────────────│ (2)
  │      SDP                       │
  │                                │
  │ ──── ACK ─────────────────────>│ (3)
  │                                │
  │ <═════════ RTP 流 ════════════│ (4)
  │                                │
  │ ──── INFO (PLAY) ─────────────>│ (5)
  │                                │
  │ <─── 200 OK ──────────────────│ (6)
  │                                │
  │ <─── MESSAGE (MediaStatus) ───│ (7)
  │                                │
  │ ──── 200 OK ─────────────────>│ (8)
  │                                │
  │ ──── BYE ─────────────────────>│ (9)
  │                                │
  │ <─── 200 OK ──────────────────│ (10)
```

### INVITE请求

```sip
INVITE sip:34020000001310000001@192.168.1.200:5060 SIP/2.0
Via: SIP/2.0/UDP 192.168.1.100:5060;rport;branch=z9hG4bK-xxx
From: <sip:34020000002000000001@3402000000>;tag=e3719a0b
To: <sip:34020000001310000001@3402000000>
Call-ID: wlss-f7c53b46-eea27828118c3b50449185980f4bfdf0@192.168.1.100
CSeq: 1 INVITE
Contact: <sip:192.168.1.100:5060>
Subject: 34020000001310000001:0100000001,34020000002000000001:0
Content-Type: APPLICATION/SDP
Max-Forwards: 70

v=0
o=34020000002000000001 100 IN IP4 192.168.1.100
s=Playback
u=34020000001310000001:3
c=IN IP4 192.168.1.100
t=1288625085 1288625871
m=video 6000 RTP/AVP 96 97 98
a=recvonly
a=rtpmap:96 PS/90000
a=rtpmap:97 MPEG4/90000
a=rtpmap:98 H264/90000
```

### SDP关键字段

| 字段 | 说明 |
|------|------|
| s=Playback | 会话类型为录像回放 |
| u=设备ID:录像序号 | 标识录像文件 |
| t=开始时间 结束时间 | 录像时间范围（NTP时间戳） |

## MANSRTSP控制协议

### 协议格式

MANSRTSP消息通过SIP INFO方法传输：

```
INFO sip:设备@地址 SIP/2.0
Content-Type: Application/MANSRTSP

命令 MANSRTSP/1.0
CSeq: 序列号
参数: 值
```

### PLAY命令

开始或恢复播放：

```
PLAY MANSRTSP/1.0
CSeq: 5
Scale: 1.0
Range: npt=196-
```

**参数说明**:

| 参数 | 说明 |
|------|------|
| Scale | 播放速度（1.0=正常，2.0=2倍速） |
| Range | 播放范围（npt=开始时间-） |

### PAUSE命令

暂停播放：

```
PAUSE MANSRTSP/1.0
CSeq: 1
PauseTime: now
```

### TEARDOWN命令

停止播放：

```
TEARDOWN MANSRTSP/1.0
CSeq: 1
```

### 播放速度

| Scale值 | 说明 |
|---------|------|
| 1.0 | 正常速度 |
| 2.0 | 2倍速快进 |
| 0.5 | 半速慢放 |
| -1.0 | 正常速度倒放 |
| -2.0 | 2倍速倒放 |

### Range格式

| 格式 | 说明 |
|------|------|
| npt=now- | 从当前位置开始 |
| npt=100- | 从第100秒开始 |
| npt=100-200 | 从第100秒到第200秒 |

## 媒体状态通知

### MediaStatus消息

设备发送媒体状态通知：

```xml
<?xml version="1.0"?>
<Notify>
  <CmdType>MediaStatus</CmdType>
  <SN>8</SN>
  <DeviceID>34020000001310000001</DeviceID>
  <NotifyType>121</NotifyType>
</Notify>
```

### NotifyType值

| 值 | 说明 |
|----|------|
| 121 | 回放结束/文件结束 |

## 完整回放示例

### 1. 开始回放

```
平台 -> 设备: INVITE (s=Playback, t=时间范围)
设备 -> 平台: 200 OK (SDP)
平台 -> 设备: ACK
```

### 2. 播放控制

```
平台 -> 设备: INFO (PLAY, Range=npt=开始时间-)
设备 -> 平台: 200 OK
```

### 3. 暂停

```
平台 -> 设备: INFO (PAUSE)
设备 -> 平台: 200 OK
```

### 4. 快进

```
平台 -> 设备: INFO (PLAY, Scale=2.0)
设备 -> 平台: 200 OK
```

### 5. 定位

```
平台 -> 设备: INFO (PLAY, Range=npt=指定时间-)
设备 -> 平台: 200 OK
```

### 6. 结束

```
平台 -> 设备: BYE
设备 -> 平台: 200 OK
```

## 注意事项

1. **时间戳格式**
   - t字段使用NTP时间戳（从1900年1月1日开始的秒数）
   - 或使用UNIX时间戳+2208988800转换为NTP

2. **SSRC处理**
   - 回放使用不同于实时的SSRC
   - 用于区分实时流和回放流

3. **文件标识**
   - u字段格式：设备ID:录像序号
   - 录像序号由设备分配

4. **错误处理**
   - 文件不存在返回488
   - 播放结束发送MediaStatus通知

5. **倍速支持**
   - 不是所有设备都支持所有倍速
   - 需要协商支持的倍速
