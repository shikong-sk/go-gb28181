# GB/T 28181-2016 PTZ云台控制

## 概述

PTZ (Pan-Tilt-Zoom) 云台控制用于控制摄像机的水平转动、垂直转动和变倍操作。

## 控制命令

### MANSCDP控制消息

```xml
<?xml version="1.0"?>
<Control>
  <CmdType>DeviceControl</CmdType>
  <SN>11</SN>
  <DeviceID>34020000001320000001</DeviceID>
  <PTZCmd>A50F4D1000001021</PTZCmd>
  <Info>
    <ControlPriority>5</ControlPriority>
  </Info>
</Control>
```

### 控制响应

```xml
<?xml version="1.0"?>
<Response>
  <CmdType>DeviceControl</CmdType>
  <SN>11</SN>
  <DeviceID>34020000001320000001</DeviceID>
  <Result>OK</Result>
</Response>
```

## PTZCmd 编码格式

PTZCmd 为 8 字节十六进制字符串，格式如下：

### 字节结构

| 字节 | 名称 | 说明 |
|------|------|------|
| 1 | 起始码 | A5H（固定） |
| 2 | 组合码 | 0FH（固定同步字节） |
| 3 | 组合码 | 01H（固定） |
| 4 | 指令码 | 指令类型 + 方向组合 |
| 5 | 水平速度 | 00H-FFH |
| 6 | 垂直速度 | 00H-FFH |
| 7 | 组合码 | 预置位/聚焦/光圈控制 |
| 8 | 校验码 | 字节1-7累加和 mod 256 |

### 字节4详解（指令码）

字节4编码方向和动作类型：

| 指令码 | 动作 |
|--------|------|
| 00H | 停止 |
| 01H | 左转 |
| 02H | 右转 |
| 04H | 上转 |
| 08H | 下转 |
| 10H | 变倍近（缩小） |
| 20H | 变倍远（放大） |
| 05H | 左上 |
| 06H | 右上 |
| 09H | 左下 |
| 0AH | 右下 |

**指令组合规则**：
- 水平方向：Bit0=左(01H)，Bit1=右(02H)
- 垂直方向：Bit2=上(04H)，Bit3=下(08H)
- 变倍：Bit4=近(10H)，Bit5=远(20H)
- 组合控制：多个位组合（如左上=01H+04H=05H）

### 校验码计算

**正确的校验码计算方法**：

```
校验码 = (Byte1 + Byte2 + Byte3 + Byte4 + Byte5 + Byte6 + Byte7) mod 256
```

**注意**：校验码是**累加和取模**，不是异或（XOR）！

## 基本控制命令

### 停止

```
PTZCmd: A5 0F 01 00 00 00 00 B5
校验码计算: (A5 + 0F + 01 + 00 + 00 + 00 + 00) mod 256 = B5H
```

### 水平方向控制

| 方向 | PTZCmd示例 |
|------|------------|
| 左（速度32） | A5 0F 01 01 20 00 00 F5 |
| 右（速度32） | A5 0F 01 02 20 00 00 F6 |
| 停止 | A5 0F 01 00 00 00 00 B5 |

### 垂直方向控制

| 方向 | PTZCmd示例 |
|------|------------|
| 上（速度32） | A5 0F 01 04 00 20 00 F9 |
| 下（速度32） | A5 0F 01 08 00 20 00 FD |
| 停止 | A5 0F 01 00 00 00 00 B5 |

### 变倍控制

| 动作 | PTZCmd示例 |
|------|------------|
| 变倍近 | A5 0F 01 10 00 00 20 E5 |
| 变倍远 | A5 0F 01 20 00 00 20 F5 |

### 组合控制

| 动作 | PTZCmd示例 |
|------|------------|
| 左上 | A5 0F 01 05 20 20 00 FA |
| 右上 | A5 0F 01 06 20 20 00 FB |
| 左下 | A5 0F 01 09 20 20 00 FE |
| 右下 | A5 0F 01 0A 20 20 00 FF |

## 预置位控制

### 预置位命令格式

| 命令 | 字节5 | 字节6 |
|------|-------|-------|
| 设置预置位 | 01H | 预置位号 |
| 调用预置位 | 02H | 预置位号 |
| 删除预置位 | 03H | 预置位号 |

### 设置预置位

```
PTZCmd: A5 00 00 00 01 预置位号 00 校验码
```

**示例**（设置预置位1）:
```
A5 00 00 00 01 01 00 A5
```

### 调用预置位

```
PTZCmd: A5 00 00 00 02 预置位号 00 校验码
```

**示例**（调用预置位1）:
```
A5 00 00 00 02 01 00 A6
```

### 删除预置位

```
PTZCmd: A5 00 00 00 03 预置位号 00 校验码
```

## 聚焦控制

### 字节7编码

| Bit | 功能 | 值 |
|-----|------|-----|
| Bit7-4 | 固定0 | - |
| Bit3 | 聚焦方向 | 0=远, 1=近 |
| Bit2 | 聚焦控制 | 0=停止, 1=动作 |
| Bit1 | 光圈方向 | 0=关, 1=开 |
| Bit0 | 光圈控制 | 0=停止, 1=动作 |

### 聚焦命令

| 动作 | PTZCmd |
|------|--------|
| 聚焦近 | A5 00 00 00 00 00 0C A9 |
| 聚焦远 | A5 00 00 00 00 00 04 A1 |
| 聚焦停止 | A5 00 00 00 00 00 00 A5 |

### 光圈命令

| 动作 | PTZCmd |
|------|--------|
| 光圈开 | A5 00 00 00 00 00 03 A6 |
| 光圈关 | A5 00 00 00 00 00 01 A4 |
| 光圈停止 | A5 00 00 00 00 00 00 A5 |

## 速度值映射

### 速度范围

- 水平速度：00H-FFH (0-255)
- 垂直速度：00H-FFH (0-255)

### 速度映射

| 十六进制 | 十进制 | 实际速度 |
|----------|--------|----------|
| 00H | 0 | 停止 |
| 20H | 32 | 低速 |
| 40H | 64 | 中速 |
| 80H | 128 | 高速 |
| FFH | 255 | 最高速 |

## 控制优先级

在Info字段中指定控制优先级：

```xml
<Info>
  <ControlPriority>5</ControlPriority>
</Info>
```

| 优先级 | 说明 |
|--------|------|
| 1-3 | 低优先级 |
| 4-6 | 中优先级 |
| 7-10 | 高优先级 |

## PTZ查询

### 预置位查询

```xml
<?xml version="1.0"?>
<Query>
  <CmdType>PresetQuery</CmdType>
  <SN>1</SN>
  <DeviceID>34020000001320000001</DeviceID>
</Query>
```

### 预置位响应

```xml
<?xml version="1.0"?>
<Response>
  <CmdType>PresetQuery</CmdType>
  <SN>1</SN>
  <DeviceID>34020000001320000001</DeviceID>
  <PresetList Num="10">
    <Item>
      <PresetID>1</PresetID>
      <PresetName>入口</PresetName>
    </Item>
    <Item>
      <PresetID>2</PresetID>
      <PresetName>出口</PresetName>
    </Item>
  </PresetList>
</Response>
```

## 注意事项

1. **校验码必须正确**：错误的校验码会导致命令被忽略

2. **速度值适中**：过高的速度可能导致云台抖动

3. **预置位号范围**：1-255，0通常不使用

4. **控制优先级**：高优先级可以抢占低优先级的控制权

5. **停止命令**：控制完成后应发送停止命令

6. **超时处理**：长时间无响应需要重发或报错
