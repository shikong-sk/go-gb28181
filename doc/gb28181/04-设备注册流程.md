# GB/T 28181-2016 设备注册流程

## 注册概述

SIP设备通过REGISTER请求向SIP服务器注册，建立设备与服务器之间的绑定关系。

## 基本注册流程

### 流程图

```
设备                                    SIP服务器
  │                                       │
  │ ──────── REGISTER ──────────────────> │ (1)
  │                                       │
  │ <─────── 401 Unauthorized ─────────── │ (2)
  │          WWW-Authenticate             │
  │                                       │
  │ ──────── REGISTER ──────────────────> │ (3)
  │          Authorization                │
  │                                       │
  │ <─────── 200 OK ──────────────────── │ (4)
  │          Date                         │
  │          Contact                      │
  │          Expires                      │
```

### 流程说明

1. **设备发送REGISTER请求**
   - Contact头域包含设备地址
   - Expires头域指定注册有效期（建议3600秒）

2. **服务器返回401 Unauthorized**
   - WWW-Authenticate头域包含认证参数
   - realm为SIP域编码
   - nonce为随机挑战码

3. **设备重新发送REGISTER请求**
   - Authorization头域包含认证响应
   - response = MD5(username:realm:password:nonce:uri)

4. **服务器返回200 OK**
   - Date头域返回服务器时间
   - Contact头域确认注册地址
   - Expires头域确认有效期

## 数字摘要认证

### 流程图

```
设备                                    SIP服务器
  │                                       │
  │ ──────── REGISTER ──────────────────> │ (1)
  │          Authorization: Capability    │
  │                                       │
  │ <─────── 401 Unauthorized ─────────── │ (2)
  │          WWW-Authenticate: Asymmetric │
  │                                       │
  │ ──────── REGISTER ──────────────────> │ (3)
  │          Authorization: Asymmetric    │
  │                                       │
  │ <─────── 200 OK ──────────────────── │ (4)
```

### Authorization Capability

设备在首次REGISTER中声明支持的算法：

```
Authorization: Capability algorithm="A:RSA/ECB/PKCS1,RSA/CBC/PKCS1;
               H:SHA1,MD5,SHA256;
               S:DES/ECB/PKCS5,DES/CBC/PKCS5,3DES/ECB/PKCS5,3DES/CBC/PKCS5,SCB2"
```

### WWW-Authenticate Asymmetric

服务器返回加密挑战：

```
WWW-Authenticate: Asymmetric nonce="加密数据", algorithm="A:RSA/ECB/PKCS1&SHA1"
```

### Authorization Asymmetric

设备返回解密响应：

```
Authorization: Asymmetric nonce="加密数据", response="响应值", algorithm=SHA1
```

## 注销流程

### 流程说明

设备发送Expires为0的REGISTER请求，服务器删除注册信息。

### 流程图

```
设备                                    SIP服务器
  │                                       │
  │ ──────── REGISTER ──────────────────> │
  │          Expires: 0                   │
  │                                       │
  │ <─────── 401 Unauthorized ─────────── │
  │                                       │
  │ ──────── REGISTER ──────────────────> │
  │          Expires: 0                   │
  │          Authorization                │
  │                                       │
  │ <─────── 200 OK ──────────────────── │
```

## 心跳保活

### 心跳机制

- 设备周期性发送Keepalive消息
- 默认心跳间隔：60秒
- 默认心跳超时次数：3次
- 超时后服务器标记设备离线

### Keepalive消息

```sip
MESSAGE sip:3402000000@192.168.1.100:5060 SIP/2.0
Via: SIP/2.0/UDP 192.168.1.200:5060;rport;branch=z9hG4bK-xxx
From: <sip:34020000002000000001@3402000000>;tag=xxx
To: <sip:3402000000@3402000000>
Call-ID: xxx@192.168.1.200
CSeq: 1 MESSAGE
Content-Type: Application/MANSCDP+xml
Max-Forwards: 70
Content-Length: xxx

<?xml version="1.0"?>
<Notify>
  <CmdType>Keepalive</CmdType>
  <SN>1</SN>
  <DeviceID>34020000002000000001</DeviceID>
  <Status>OK</Status>
</Notify>
```

### 心跳响应

```sip
SIP/2.0 200 OK
Via: SIP/2.0/UDP 192.168.1.200:5060;rport;branch=z9hG4bK-xxx
From: <sip:34020000002000000001@3402000000>;tag=xxx
To: <sip:3402000000@3402000000>;tag=xxx
Call-ID: xxx@192.168.1.200
CSeq: 1 MESSAGE
Content-Length: 0
```

## 注册参数配置

### 设备端配置

| 参数 | 说明 | 建议值 |
|------|------|--------|
| 注册间隔 | REGISTER周期 | 3600秒 |
| 心跳间隔 | Keepalive周期 | 60秒 |
| 心跳超时次数 | 判定离线阈值 | 3次 |
| 注册有效期 | 最大有效期 | 86400秒 |

### 服务器端配置

| 参数 | 说明 | 建议值 |
|------|------|--------|
| 注册有效期范围 | 最小~最大 | 60~86400秒 |
| 心跳超时时间 | 判定离线时间 | 180秒 |
| nonce有效期 | 认证挑战有效期 | 600秒 |

## 注意事项

1. **注册过期处理**
   - 设备应在Expires到期前重新注册
   - 建议在Expires的1/2时间时重新注册

2. **认证计算**
   - response = MD5(username:realm:password:nonce:uri)
   - 注意密码通常为空或设备ID

3. **Call-ID处理**
   - 同一注册会话使用相同Call-ID
   - CSeq递增

4. **心跳同步**
   - 心跳消息不要求认证
   - 连续3次心跳失败判定离线

5. **多网卡设备**
   - Contact地址应为可路由地址
   - Via中包含rport参数支持NAT
