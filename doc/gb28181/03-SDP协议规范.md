# GB/T 28181-2016 SDP协议规范

## SDP协议概述

SDP (Session Description Protocol) 用于描述多媒体会话参数，基于 IETF RFC 4566。GB/T 28181 在标准 SDP 基础上进行了扩展。

## SDP 消息结构

### 基本结构

```
v=0
o=<用户名> <会话ID> <版本> <网络类型> <地址类型> <地址>
s=<会话名称>
c=<网络类型> <地址类型> <连接地址>
t=<开始时间> <结束时间>
m=<媒体类型> <端口> <传输协议> <格式列表>
a=<属性行>
y=<SSRC>
f=<媒体参数>
```

### 必选字段

| 字段 | 说明 | GB28181要求 |
|------|------|-------------|
| v | 协议版本 | 必须为 0 |
| o | 会话所有者 | 用户名为设备ID |
| s | 会话名称 | Play/Playback/Download/Talk |
| c | 连接信息 | IP地址 |
| t | 时间 | 必须为 0 0 |
| m | 媒体描述 | 端口、传输协议、格式 |
| a | 属性行 | rtpmap、recvonly/sendonly |
| y | SSRC | 10位十进制数字 |
| f | 媒体参数 | 视频音频编码参数 |

## 字段详细规范

### v (Protocol Version)

```
v=0
```

固定为 0。

### o (Origin)

```
o=<username> <session id> <version> <nettype> <addrtype> <unicast-address>
```

| 参数 | 说明 | 示例 |
|------|------|------|
| username | 设备ID（20位） | 34020000002000000001 |
| session id | 会话ID | 100 |
| version | 版本号 | 0 |
| nettype | 网络类型 | IN |
| addrtype | 地址类型 | IP4 |
| unicast-address | IP地址 | 192.168.1.100 |

**示例**:
```
o=34020000002000000001 100 IN IP4 192.168.1.100
```

### s (Session Name)

会话名称标识会话类型：

| 会话名称 | 用途 |
|----------|------|
| Play | 实时点播 |
| Playback | 录像回放 |
| Download | 录像下载 |
| Talk | 语音对讲 |

### c (Connection Data)

```
c=<nettype> <addrtype> <connection-address>
```

| 参数 | 说明 |
|------|------|
| nettype | 网络类型，固定为 IN |
| addrtype | 地址类型，IP4 或 IP6 |
| connection-address | IP地址 |

**示例**:
```
c=IN IP4 192.168.1.100
```

### t (Timing)

```
t=<start-time> <stop-time>
```

- GB28181 规定必须为 `t=0 0`
- 对于录像回放，时间信息通过 `u` 和 `t` 字段传递

### m (Media)

```
m=<media> <port> <proto> <fmt> ...
```

| 参数 | 说明 |
|------|------|
| media | 媒体类型：video 或 audio |
| port | 媒体端口 |
| proto | 传输协议：RTP/AVP 或 TCP/RTP/AVP |
| fmt | 格式列表（Payload Type） |

**传输协议**:
- `RTP/AVP`: RTP over UDP
- `TCP/RTP/AVP`: RTP over TCP

**示例**:
```
m=video 6000 RTP/AVP 96 98 97
m=audio 8000 RTP/AVP 8
```

### a (Attributes)

#### rtpmap 属性

```
a=rtpmap:<payload type> <encoding name>/<clock rate>[/<encoding parameters>]
```

**视频编码**:
| PT | 编码名 | 时钟频率 |
|----|--------|----------|
| 96 | PS | 90000 |
| 97 | MPEG4 | 90000 |
| 98 | H264 | 90000 |

**音频编码**:
| PT | 编码名 | 时钟频率 |
|----|--------|----------|
| 8 | PCMA | 8000 |
| 4 | G723 | 8000 |
| 18 | G729 | 8000 |
| 9 | G722 | 8000 |

**示例**:
```
a=rtpmap:96 PS/90000
a=rtpmap:98 H264/90000
a=rtpmap:97 MPEG4/90000
a=rtpmap:8 PCMA/8000
```

#### 方向属性

| 属性 | 说明 | 使用场景 |
|------|------|----------|
| recvonly | 只接收 | 平台请求设备发流 |
| sendonly | 只发送 | 设备响应平台请求 |
| sendrecv | 收发双向 | 双向通信 |

#### 其他属性

```
a=downloadspeed:<speed>     // 下载倍速
a=filesize:<size>           // 文件大小（字节）
a=setup:<role>              // TCP连接角色：active/passive
a=connection:new            // TCP连接类型
```

### y (SSRC)

```
y=<ssrc>
```

- 10位十进制数字
- 用于唯一标识 RTP 流
- 不能全为0，不能全为1

**SSRC格式规则**:

| 位 | 说明 |
|----|------|
| 第1-8位 | SIP监控域编码ID的后8位（0~2620对应实际域编码） |
| 第9位 | 流类型：0=实时流，1=历史流（回放/下载） |
| 第10位 | 域内序号（0-9） |

**示例**:
- 实时流SSRC: `3402000001`（域编码后8位=34020000，实时流=0，序号=1）
- 历史流SSRC: `3402000011`（域编码后8位=34020000，历史流=1，序号=1）

### f (Media Parameters)

```
f=v/<视频编码>/<分辨率>/<码率类型>/<码率> a/<音频编码>/<码率>/<采样率>
```

**视频编码（v）**:
| 编码值 | 编码类型 |
|--------|----------|
| 1 | MPEG-4 |
| 2 | H.264 |
| 3 | SVAC |
| 4 | 3GP |

**分辨率**:
| 值 | 分辨率 |
|----|--------|
| 1 | QCIF |
| 2 | CIF |
| 3 | 4CIF |
| 4 | D1 |
| 5 | 720P |
| 6 | 1080P |

**码率类型**:
| 值 | 类型 |
|----|------|
| 1 | CBR（固定码率） |
| 2 | VBR（可变码率） |

**音频编码（a）**:
| 编码值 | 编码类型 |
|--------|----------|
| 1 | G.711 |
| 2 | G.723.1 |
| 3 | G.729 |
| 4 | G.722.1 |

**音频码率**:
| 编码值 | 码率 | 适用编码 |
|--------|------|----------|
| 1 | 5.3kbps | G.723.1 |
| 2 | 6.3kbps | G.723.1 |
| 3 | 8kbps | G.729 |
| 4 | 16kbps | G.722.1 |
| 5 | 24kbps | G.722.1 |
| 6 | 32kbps | G.722.1 |
| 7 | 48kbps | G.722.1 |
| 8 | 64kbps | G.711 |

**音频采样频率**:
| 编码值 | 采样频率 | 适用编码 |
|--------|----------|----------|
| 1 | 8kHz | G.711/G.723.1/G.729 |
| 2 | 14kHz | G.722.1 |
| 3 | 16kHz | G.722.1 |
| 4 | 32kHz | G.722.1 |

**示例**:
```
f=v/2/5/1/4096 a/1/8/1
```
表示：H.264编码，720P分辨率，CBR码率，4096kbps；G.711音频，64kbps，8kHz。

**省略规则**:
- 只有视频时可省略音频部分：`f=v/2/5/1/4096`
- 只有音频时可省略视频部分：`f=a/1/8/1`
- 部分字段可省略，用空值表示

### u (URI)

用于录像回放场景，标识录像文件：

```
u=<deviceID>:<recorderID>
```

**示例**:
```
u=34020000001310000001:3
```

## 完整SDP示例

### 实时点播请求（平台→设备）

```
v=0
o=34020000002000000001 100 IN IP4 192.168.1.100
s=Play
c=IN IP4 192.168.1.100
t=0 0
m=video 6000 RTP/AVP 96 97 98
a=recvonly
a=rtpmap:96 PS/90000
a=rtpmap:97 MPEG4/90000
a=rtpmap:98 H264/90000
y=0100000001
```

### 设备响应（设备→平台）

```
v=0
o=34020000001320000001 100 IN IP4 192.168.1.200
s=Play
c=IN IP4 192.168.1.200
t=0 0
m=video 6000 RTP/AVP 96
a=sendonly
a=rtpmap:96 PS/90000
y=1000000001
f=v/2/5/1/4096
```

### 录像回放请求

```
v=0
o=34020000002000000001 100 IN IP4 192.168.1.100
s=Playback
u=34020000001310000001:3
c=IN IP4 192.168.1.100
t=1288625085 1288625871
m=video 6000 RTP/AVP 96
a=recvonly
a=rtpmap:96 PS/90000
y=0100000001
```

### 录像下载请求

```
v=0
o=34020000002000000001 100 IN IP4 192.168.1.100
s=Download
u=34020000001310000001:3
c=IN IP4 192.168.1.100
t=1288625085 1288625871
m=video 6000 RTP/AVP 96
a=recvonly
a=rtpmap:96 PS/90000
a=downloadspeed:4
y=0100000001
```

### 语音对讲请求

```
v=0
o=34020000002000000001 100 IN IP4 192.168.1.100
s=Talk
c=IN IP4 192.168.1.100
t=0 0
m=audio 8000 RTP/AVP 8
a=sendrecv
a=rtpmap:8 PCMA/8000
y=0100000001
f=a/1/8/1
```

### TCP传输请求

```
v=0
o=34020000002000000001 100 IN IP4 192.168.1.100
s=Play
c=IN IP4 192.168.1.100
t=0 0
m=video 6000 TCP/RTP/AVP 96
a=recvonly
a=rtpmap:96 PS/90000
a=setup:active
a=connection:new
y=0100000001
```

## SDP处理规则

### SSRC处理

1. **平台发起请求时**：平台生成SSRC，在INVITE请求的SDP中携带
2. **设备响应时**：设备使用平台提供的SSRC或生成自己的SSRC

### 时间字段

- 实时点播：`t=0 0`
- 录像回放/下载：`t=<开始时间> <结束时间>`（UNIX时间戳）

### 媒体协商

1. 平台在INVITE中提供支持的编码格式列表
2. 设备在200 OK中选择一种格式响应
3. 如果不支持，返回488错误

### 端口处理

- 平台在INVITE中提供接收媒体的端口
- 设备在200 OK中提供发送媒体的端口

## 注意事项

1. **s字段必须正确**：Play/Playback/Download/Talk区分不同会话类型
2. **y字段必须为10位**：SSRC用于媒体流标识
3. **f字段可选**：但建议携带，便于解析编码参数
4. **TCP传输**：需要设置 `a=setup` 和 `a=connection` 属性
5. **录像时间**：录像回放/下载时t字段为实际录像时间范围
