# GB/T 28181-2016 安全认证机制

## 概述

GB/T 28181 定义了完整的安全认证机制，包括数字摘要认证、信令加密、媒体加密等。

## 数字摘要认证

### 基本流程

```
设备                                    服务器
  │                                       │
  │ ──────── REGISTER ──────────────────> │
  │                                       │
  │ <─────── 401 Unauthorized ─────────── │
  │          WWW-Authenticate             │
  │                                       │
  │ ──────── REGISTER ──────────────────> │
  │          Authorization                │
  │                                       │
  │ <─────── 200 OK ──────────────────── │
```

### WWW-Authenticate 头域

```
WWW-Authenticate: Digest realm="3402000000", 
                  nonce="6fe9ba44a76be22a",
                  algorithm=MD5
```

| 参数 | 说明 |
|------|------|
| realm | SIP域编码 |
| nonce | 服务器生成的随机挑战码 |
| algorithm | 哈希算法（MD5/SHA-1/SHA-256） |

### Authorization 头域

```
Authorization: Digest username="34020000002000000001",
               realm="3402000000",
               nonce="6fe9ba44a76be22a",
               uri="sip:3402000000@192.168.1.100:5060",
               response="9625d92d1bddea7a911926e0db054968",
               algorithm=MD5
```

### response 计算

```
response = MD5(MD5(username:realm:password):nonce:MD5(uri))
```

**计算步骤**:
1. HA1 = MD5(username:realm:password)
2. HA2 = MD5(method:uri)
3. response = MD5(HA1:nonce:HA2)

## 非对称加密认证

### 认证流程

```
设备                                    服务器
  │                                       │
  │ ──────── REGISTER ──────────────────> │
  │          Authorization: Capability    │
  │                                       │
  │ <─────── 401 Unauthorized ─────────── │
  │          WWW-Authenticate: Asymmetric │
  │                                       │
  │ ──────── REGISTER ──────────────────> │
  │          Authorization: Asymmetric    │
  │                                       │
  │ <─────── 200 OK ──────────────────── │
```

### Capability 声明

设备声明支持的加密算法：

```
Authorization: Capability 
  algorithm="A:RSA/ECB/PKCS1,RSA/CBC/PKCS1;
             H:SHA1,MD5,SHA256;
             S:DES/ECB/PKCS5,DES/CBC/PKCS5,3DES/ECB/PKCS5,3DES/CBC/PKCS5,SCB2"
```

**算法类型**:
- A: 非对称加密算法（RSA）
- H: 哈希算法（SHA-1, MD5, SHA-256）
- S: 对称加密算法（DES, 3DES, SCB2）

### Asymmetric 认证

服务器返回加密挑战：

```
WWW-Authenticate: Asymmetric 
  nonce="加密数据",
  algorithm="A:RSA/ECB/PKCS1&SHA1"
```

设备解密并响应：

```
Authorization: Asymmetric 
  nonce="加密数据",
  response="响应值",
  algorithm=SHA1
```

## 信令安全

### TLS 传输

SIP信令通过TLS加密传输：

```
sips:34020000002000000001@3402000000
```

### S/MIME 加密

对SIP消息体进行S/MIME加密：

```
Content-Type: application/pkcs7-mime; smime-type=enveloped-data
```

### IPSec

网络层安全传输：
- AH (Authentication Header)
- ESP (Encapsulating Security Payload)

## 证书管理

### X.509证书

采用X.509 v3证书格式：

| 字段 | 要求 |
|------|------|
| 版本 | V3 |
| 序列号 | 唯一 |
| 签名算法 | RSA/SHA-1 |
| 颁发者 | CA信息 |
| 有效期 | 起止时间 |
| 主体 | 设备/平台信息 |
| 公钥 | 1024-2048位RSA |

### 证书字段

| 字段 | 长度 | 说明 |
|------|------|------|
| CN (Common Name) | 8字符 | 通用名称 |
| L (Locality) | 2字符 | 地区代码(GB/T 2260) |
| S (State) | 2字符 | 省份代码 |
| C (Country) | 2字符 | 国家代码(GB/T 2659) |

### CRL 证书撤销列表

X.509 v2 CRL格式：
- 撤销证书列表
- 撤销时间
- CRL有效期

## 媒体加密

### 媒体流加密

对RTP媒体流进行加密：
- AES加密
- DES/3DES加密
- SM1国密算法

### 加密协商

通过SDP协商加密参数：

```
a=crypto:1 AES_CM_128_HMAC_SHA1_80 inline:密钥
```

## 用户身份认证

### Monitor-User-Identity 头域

用于身份验证：

```
Monitor-User-Identity: 设备ID
```

### 身份验证流程

1. 服务器验证用户身份
2. 生成身份令牌
3. 在后续请求中携带令牌

## 时间戳验证

### Date 头域

服务器返回时间：

```
Date: 2010-11-02T15:01:26.115
```

### 时间同步

- 通过NTP同步时间
- 通过SIP Date头域校准
- 允许误差：10小时

### 防重放攻击

1. 记录已使用的nonce
2. nonce有效期：10分钟
3. 验证时间戳在有效范围内

## 安全配置示例

### 设备端配置

```toml
[security]
# 认证方式
auth_type = "digest"  # digest/asymmetric

# 支持的算法
algorithms = ["MD5", "SHA-1"]

# 证书配置
cert_file = "/path/to/cert.pem"
key_file = "/path/to/key.pem"

# TLS配置
tls_enable = true
tls_verify = true
```

### 服务器端配置

```toml
[security]
# nonce有效期
nonce_expire = 600

# 密码策略
password_min_length = 8

# 证书配置
ca_file = "/path/to/ca.pem"
cert_file = "/path/to/server.pem"
key_file = "/path/to/server.key"

# TLS配置
tls_port = 5061
```

## 注意事项

1. **密钥保护**
   - 密钥存储在安全位置
   - 定期更换密钥

2. **证书管理**
   - 监控证书有效期
   - 及时更新过期证书

3. **时间同步**
   - 确保设备时间正确
   - 使用NTP服务器同步

4. **nonce管理**
   - nonce必须唯一
   - 已使用的nonce要记录

5. **错误处理**
   - 认证失败要有明确提示
   - 防止暴力破解

6. **日志审计**
   - 记录认证事件
   - 监控异常访问
