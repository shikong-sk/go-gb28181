# GB/T 28181-2016 术语和定义

## 基础术语

### 视频监控联网系统 (Video Surveillance Network System for Public Security)

以维护公共安全为目的，综合应用视音频监控、通信、计算机网络、系统集成等技术，构建的具有信息采集、传输、交换、控制、显示、存储、处理等功能的能够实现不同设备及系统间互联、互通、互控的综合视频监控系统。

### 联网系统数据 (Data of Network System)

联网系统内传输、交换、控制的信息，包括：设备信息、用户信息、业务数据、管理数据等。

### 前端设备 (Front-end Device)

监控系统的信息采集和输入设备，如：摄像机、视频服务器等。

### 监控点 (Surveillance Site)

前端设备安装的物理位置及其监控范围。

### 监控中心 (Surveillance Center)

对监控系统进行管理和控制的场所，可划分为一级、二级、三级等。

### 用户终端 (User Terminal)

用于访问监控系统资源的客户端设备或软件。

### 数字接入 (Digital Access)

前端设备以数字信号方式接入联网系统，如：DVR、DVS、IPC等。

### 模拟接入 (Analog Access)

前端设备以模拟信号方式接入联网系统。

## SIP 相关术语

### 会话初始协议 (Session Initiation Protocol, SIP)

IETF RFC 3261 定义的用于创建、修改和终止多媒体会话的应用层控制协议。

### SIP监控域 (SIP Surveillance Realm)

SIP设备、SIP客户端以及监控中心服务器构成的域，域内设备使用统一的域编码标识。

### 非SIP监控域 (Non-SIP Surveillance Realm)

不支持SIP协议的监控系统，需要通过网关与SIP监控域互联。

### 第三方控制器 (Third Party Controller)

作为SIP用户代理(UA)，可以代表其他用户建立会话的功能实体，也称为背靠背用户代理(B2BUA)。

### 用户代理 (User Agent, UA)

IETF RFC 3261 定义的SIP终端实体，包括：
- **UAC (User Agent Client)**: 发起请求的一方
- **UAS (User Agent Server)**: 响应请求的一方

### 代理服务器 (Proxy Server)

IETF RFC 3261 定义的SIP中间实体，代表其他客户端发起请求，既充当UAS也充当UAC。

### 注册服务器 (Register Server)

IETF RFC 3261 定义的SIP服务器，接收REGISTER请求，完成用户注册和位置管理。

### 重定向服务器 (Redirect Server)

IETF RFC 3261 定义的SIP服务器，将请求重定向到其他地址。

### 背靠背用户代理 (Back-to-Back User Agent, B2BUA)

作为两个SIP用户代理的中间实体，一端作为UAS接收请求，另一端作为UAC转发请求。

## 功能实体术语

### 功能实体 (Functional Entity)

实现特定功能的逻辑单元，一个物理设备可以包含多个功能实体。

### 源设备/目标设备 (Source Device / Target Device)

信息交互的发起方称为源设备，接收方称为目标设备。

### SIP客户端 (SIP Client)

监控系统中用于访问监控资源的SIP用户代理，可以实现实时视音频点播、历史视音频回放、设备控制等业务功能。

### SIP设备 (SIP Device)

支持SIP协议的监控设备，如：IPC、DVR、DVR等。SIP设备具有SIP UA功能，支持注册、心跳、目录上报、媒体流传输等。

### 中心信令控制服务器 (Center Control Server)

SIP监控域的核心设备，负责域内SIP设备的注册、认证、信令路由等功能。

### 媒体服务器 (Media Server)

提供媒体流处理的服务器，包括：媒体流转发、媒体流存储、媒体流转换等功能。

### 安全信令网关 (Secure Signal Routing Gateway)

实现SIP监控域之间安全互联的网关设备。

### 级联网格 (Cascaded Networking)

上下级平台互联的网络结构，下级平台向上级平台注册。

### 对等网格 (Peer-to-Peer Networking)

平级平台互联的网络结构，平台之间对等通信。

## 编码相关术语

### 设备ID编码

按照GB/T 2260行政区划代码标准，采用20位数字编码：
- 第1-8位：行政区划代码
- 第9-13位：设备类型代码
- 第14-20位：设备序号

### SSRC (Synchronization Source)

RTP流同步源标识符，10位十进制数字，用于唯一标识一个RTP流。
