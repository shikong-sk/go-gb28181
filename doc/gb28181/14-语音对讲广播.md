# GB/T 28181-2016 语音对讲与广播

## 概述

语音对讲和广播功能允许平台与前端设备进行双向语音通信。

## 语音对讲

### 流程图

```
平台                              设备
  │                                │
  │ ──── INVITE ──────────────────>│ (1)
  │      SDP (s=Talk)              │
  │                                │
  │ <─── 200 OK ──────────────────│ (2)
  │      SDP                       │
  │                                │
  │ ──── ACK ─────────────────────>│ (3)
  │                                │
  │ <═══════ RTP音频流 ═══════════│ (4) 双向
  │                                │
  │ ──── BYE ─────────────────────>│ (5)
  │                                │
  │ <─── 200 OK ──────────────────│ (6)
```

|------|------|
| s=Talk | 会话类型为语音对讲 |

| a=sendrecv | 双向通信 |

## 语音广播

### 广播概述

语音广播用于向一个或多个设备发送语音，通常用于紧急通知、公共广播等场景。

### 广播流程

```
平台                    SIP服务器                设备A                设备B
  │                         │                      │                    │
  │ ──── MESSAGE ──────────>│                      │                    │
  │      Broadcast Notify   │                      │                    │
  │                         │                      │                    │
  │ <─── 200 OK ───────────│                      │                    │
  │                         │                      │                    │
  │                         │ ──── MESSAGE ───────>│                    │
  │                         │      Broadcast Notify│                    │
  │                         │                      │                    │
  │                         │ <─── 200 OK ─────────│                    │
  │                         │                      │                    │
  │                         │ ──── MESSAGE ────────────────────────────>│
  │                         │      Broadcast Notify                     │
  │                         │                                           │
  │                         │ <─── 200 OK ──────────────────────────────│
  │                         │                      │                    │
  │ ──── INVITE ────────────────────────────────>│                    │
  │      SDP (s=Play, m=audio)                    │                    │
  │                         │                      │                    │
  │ <─── 200 OK ─────────────────────────────────│                    │
  │                         │                      │                    │
  │ ──── ACK ───────────────────────────────────>│                    │
  │                         │                      │                    │
  │ ════════════════════ RTP音频流 ════════════════════════════════════
```

### 广播通知消息

## 音频编码

### 支持的音频编码

| 编码 | PT值 | 时钟频率 | 码率 |
|------|------|----------|------|
| G.711 A律 (PCMA) | 8 | 8000Hz | 64kbps |
| G.711 μ律 (PCMU) | 0 | 8000Hz | 64kbps |
| G.723.1 | 4 | 8000Hz | 5.3/6.3kbps |
| G.729 | 18 | 8000Hz | 8kbps |
| G.722.1 | 9 | 8000Hz | 16-48kbps |
| SVAC音频 | 20 | 8000Hz | - |

### SDP音频描述

```
m=audio 8000 RTP/AVP 8
a=rtpmap:8 PCMA/8000
```

## 音频参数协商

### 请求SDP

```
m=audio 8000 RTP/AVP 8 4 18
a=sendrecv
a=rtpmap:8 PCMA/8000
a=rtpmap:4 G723/8000
a=rtpmap:18 G729/8000
```

### 响应SDP

设备选择一种支持的编码：

```
m=audio 8000 RTP/AVP 8
a=sendrecv
a=rtpmap:8 PCMA/8000
```

## 音频参数字段 (f)

### f字段音频参数

```
f=a/编码/码率/采样率
```

| 参数 | 说明 |
|------|------|
| 编码 | 1=G.711, 2=G.723.1, 3=G.729, 4=G.722.1 |
| 码率 | 音频码率 |
| 采样率 | 1=8kHz, 2=14kHz, 3=16kHz, 4=32kHz |

**示例**:
```
f=a/1/8/1    // G.711, 64kbps, 8kHz
f=a/2/2/1    // G.723.1, 6.3kbps, 8kHz
```

## RTP音频传输

### 音频RTP包结构

```
+--------+--------+--------+--------+
| RTP头 | 音频数据          |
+--------+--------+--------+--------+
```

### 传输参数

| 参数 | 建议值 |
|------|--------|
| 采样间隔 | 20ms |
| 每包采样数 | 160 (8kHz) |
| 包大小 | 约200字节 |

### 时间戳计算

- 时钟频率：8000Hz
- 每帧时间戳增量：160 (20ms * 8000 / 1000)

## 对讲控制

### 静音控制

通过修改SDP方向属性：

```
a=recvonly    // 只接收（对方静音）
a=sendonly    // 只发送（己方静音）
a=sendrecv    // 双向
a=inactive    // 双向静音
```

### 音量调节

设备端可通过控制命令调节音量：

```xml
<Control>
  <CmdType>DeviceControl</CmdType>
  <SN>1</SN>
  <DeviceID>34020000001320000001</DeviceID>
  <TeleBoot>Boot</TeleBoot>
</Control>
```

## 组播广播

### 组播地址

使用组播地址进行广播：

```
c=IN IP4 239.0.0.1/128
```

### 组播优点

- 节省带宽
- 同时向多个设备发送
- 适合大规模广播

## 注意事项

1. **编码协商**
   - 平台应支持多种音频编码
   - 设备可能只支持部分编码

2. **带宽计算**
   - G.711: 64kbps + 开销 ≈ 80kbps
   - G.729: 8kbps + 开销 ≈ 24kbps

3. **延迟控制**
   - 音频延迟应小于400ms
   - 使用小包降低延迟

4. **回声消除**
   - 设备端需要回声消除功能
   - 防止音频反馈

5. **静音检测**
   - VAD (Voice Activity Detection)
   - 节省带宽

6. **广播权限**
   - 需要验证广播权限
   - 记录广播日志

7. **多设备广播**
   - 按顺序建立会话
   - 处理部分设备失败情况
