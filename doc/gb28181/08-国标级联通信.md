# GB/T 28181-2016 国标级联通信

## 级联概述

国标级联是指上下级平台之间按照GB/T 28181标准进行互联，实现跨域视频资源共享。

## 级联网络结构

### 级联网格

## 级联注册流程

### 下级平台向上级平台注册

```
下级平台                              上级平台
    │                                    │
    │ ──────── REGISTER ───────────────> │
    │                                    │
    │ <─────── 401 Unauthorized ──────── │
    │                                    │
    │ ──────── REGISTER ───────────────> │
    │          Authorization             │
    │                                    │
    │ <─────── 200 OK ───────────────── │
```

### REGISTER消息

下级平台使用平台ID（20位）进行注册：

```sip
REGISTER sip:上级域@上级IP:端口 SIP/2.0
Via: SIP/2.0/UDP 下级IP:端口;rport;branch=z9hG4bK-xxx
From: <sip:下级平台ID@下级域>;tag=xxx
To: <sip:上级域@上级域>
Call-ID: xxx@下级IP
CSeq: 1 REGISTER
Contact: <sip:下级平台ID@下级IP:端口>
Max-Forwards: 70
Expires: 3600
Content-Length: 0
```

## 跨域点播流程

### 基本流程

```
上级用户            上级平台            下级平台            下级设备
    │                  │                   │                   │
    │ ── 点播请求 ────>│                   │                   │
    │                  │ ─── INVITE ──────>│                   │
    │                  │                   │ ─── INVITE ──────>│
    │                  │                   │                   │
    │                  │                   │ <── 200 OK ───────│
    │                  │ <── 200 OK ───────│                   │
    │ <── 200 OK ──────│                   │                   │
    │                  │                   │                   │
    │                  │ ─── ACK ─────────>│                   │
    │                  │                   │ ─── ACK ─────────>│
    │                  │                   │                   │
    │ <═══════════════════════ RTP 流 ════════════════════════│
    │                  │                   │                   │
    │ ── 停止点播 ────>│                   │                   │
    │                  │ ─── BYE ─────────>│                   │
    │                  │                   │ ─── BYE ─────────>│
    │                  │                   │                   │
    │                  │                   │ <── 200 OK ───────│
    │                  │ <── 200 OK ───────│                   │
    │ <── 200 OK ──────│                   │                   │
```

### INVITE消息（上级平台→下级平台）

```sip
INVITE sip:设备ID@下级平台IP:端口 SIP/2.0
Via: SIP/2.0/UDP 上级平台IP:端口;rport;branch=z9hG4bK-xxx
From: <sip:上级平台ID@上级域>;tag=xxx
To: <sip:设备ID@下级域>
Call-ID: xxx@上级平台IP
CSeq: 1 INVITE
Contact: <sip:上级平台IP:端口>
Subject: 设备ID:设备ID,上级平台ID:0
Content-Type: APPLICATION/SDP
Max-Forwards: 70

v=0
o=上级平台ID 100 IN IP4 上级媒体IP
s=Play
c=IN IP4 上级媒体IP
t=0 0
m=video 上级媒体端口 RTP/AVP 96
a=recvonly
a=rtpmap:96 PS/90000
```

## 级联报警转发

### 报警订阅

上级平台向下级平台订阅报警：

```xml
<?xml version="1.0"?>
<Query>
  <CmdType>Alarm</CmdType>
  <SN>17430</SN>
  <DeviceID>下级平台ID</DeviceID>
  <StartAlarmPriority>1</StartAlarmPriority>
  <EndAlarmPriority>4</EndAlarmPriority>
  <AlarmMethod>0</AlarmMethod>

```

### 报警通知

下级平台向上级平台推送报警：


## 级联配置要点

### 上级平台配置

| 配置项 | 说明 |
|--------|------|
| 下级平台ID | 下级平台的20位编码 |
| 下级平台地址 | IP和端口 |
| 认证信息 | 用户名、密码 |
| 订阅周期 | 目录订阅过期时间 |

### 下级平台配置

| 配置项 | 说明 |
|--------|------|
| 上级平台ID | 上级平台的20位编码 |
| 上级平台地址 | IP和端口 |
| 注册周期 | REGISTER间隔 |
| 心跳周期 | Keepalive间隔 |

## 注意事项

1. **平台ID标识**
   - 平台使用系统编码（类型200）
   - 区别于设备编码

2. **媒体流转发**
   - B2BUA模式需要处理SSRC转换
   - 需要考虑媒体流转发性能

3. **级联深度**
   - 建议不超过3级
   - 过深会影响实时性

4. **订阅刷新**
   - 订阅需要周期刷新
   - 建议在Expires到期前刷新

5. **异常处理**
   - 级联链路断开需要重连
   - 需要处理消息丢失情况
